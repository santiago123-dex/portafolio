## Ágora Client

Aplicación cliente construida con Next.js 16 App Router, con un sistema de notificaciones en tiempo real y microservicio de gateway.

### Arquitectura

- Monorepo con pnpm workspaces
- Next.js 16 con React 19
- Agora-Notification-Gateway como microservicio
- SWR para fetching y caché de datos
- Tailwind CSS v4 para estilos
- Middleware personalizado para autenticación
